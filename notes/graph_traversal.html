Notes


DFS uses the call stack. Each call owns a frame with its own u and loop position; a recursive call suspends the caller and pushes a new frame, a return pops one. The recursion tree records every call ever made, the stack holds only the live path.


BFS uses an explicit queue. h marks the next node to dequeue, t the next free slot. Nodes are marked visited when enqueued, which is what stops duplicates. The tree is built level by level.


Honest comparison: the matrix version scans all 6 cells of a row even when most are 0, so a full traversal costs O(V^2). The list version only touches real edges, O(V+E). Matrix wins only for dense graphs or constant-time edge lookups. Also, recursive DFS in C will overflow the real stack on a deep graph; this example is tiny so it never shows that.
